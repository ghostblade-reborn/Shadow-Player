FFmpeg
------
This application includes libraries from the FFmpeg project
(https://ffmpeg.org/), version 7.1.1, built from the official
source tarball (ffmpeg-7.1.1.tar.xz) for Android arm64-v8a:

  libavcodec, libavformat, libavutil, libswresample, libswscale

FFmpeg is free software licensed under the GNU Lesser General Public
License (LGPL) version 2.1 or later. The build uses no GPL or
nonfree components: no --enable-gpl, no --enable-nonfree, and no
external codec libraries — all decoders are FFmpeg-native. Network
support is compiled out (file access only).

In accordance with the LGPL:

* The FFmpeg libraries are used as shared libraries
  (lib/arm64-v8a/libav*.so, libsw*.so) and can be replaced with a
  modified version built from the corresponding source.
* The exact corresponding source is FFmpeg 7.1.1, available from
  https://ffmpeg.org/releases/ffmpeg-7.1.1.tar.xz
* The build is reproducible: it was configured and built with the
  Android NDK r27c clang using the project build script
  (codec-lab/build-ffmpeg.sh), with networking, programs, docs,
  encoders and muxers disabled and the decoder/demuxer set limited
  to media playback.
